# Blueprint Container Test

A throwaway container image that proves the isolated image build of the blueprint, for repo-blueprint#531.

This is the start of the website of Blueprint Container Test. MkDocs builds it from the pages in `docs/`, as `mkdocs.yml` says, and every change of `main` publishes it on GitHub Pages. Replace this page with the guide for the users, and give every further page its place in the menu, `nav` in `mkdocs.yml`. German pages sit next to their English ones, such as `index.de.md` beside `index.md`, as `mkdocs.yml` shows.
